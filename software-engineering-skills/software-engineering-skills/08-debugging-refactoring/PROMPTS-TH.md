# Prompt ภาษาไทย — Debugging and Refactoring

```text
ใช้ Skill 08-debugging-refactoring วิเคราะห์ Bug นี้

ห้ามเดาสุ่มแก้ Code ทันที

ให้ทำตามลำดับ:
1. Reproduce
2. Collect Evidence
3. Form Hypotheses
4. Isolate
5. Identify Root Cause
6. Propose Minimal Fix
7. Add Regression Test
8. Verify
9. Refactor เพิ่มเติมเฉพาะเมื่อปลอดภัย

รายงาน:
- Root Cause
- Evidence
- Affected Files
- Fix
- Regression Test
- Risk of Change
```

## Prompt แบบสั้น

```text
ใช้ Skill นี้วิเคราะห์งานตาม Project ปัจจุบัน
ให้สรุป Findings / Risks / Recommendations / Verification
และอย่าแก้ไขไฟล์จนกว่าจะได้รับคำสั่ง
```
