# Prompt ภาษาไทย — Code Quality

```text
ใช้ Skill 06-code-quality Review Code ของ Project นี้

ให้ตรวจ:
- Correctness
- Readability
- Naming
- Function / Class Responsibility
- Cyclomatic Complexity
- Duplication
- Coupling / Cohesion
- Error Handling
- Dead Code
- Magic Values
- Side Effects
- Project Convention

แต่ละ Finding ให้มี:
1. Priority
2. File / Function
3. Problem
4. Why it matters
5. Recommended improvement
6. Example refactor

ยังไม่ต้องแก้ Code จนกว่าจะสั่ง
```

## Prompt แบบสั้น

```text
ใช้ Skill นี้วิเคราะห์งานตาม Project ปัจจุบัน
ให้สรุป Findings / Risks / Recommendations / Verification
และอย่าแก้ไขไฟล์จนกว่าจะได้รับคำสั่ง
```
