```text

- ออกแบบ Index ตาม Query Pattern

ผลลัพธ์:
1. ERD
2. Schema
3. Data Dictionary
4. Constraints
5. Index Strategy
6. Transaction Rules
7. Migration Plan
8. Performance Risks
```
