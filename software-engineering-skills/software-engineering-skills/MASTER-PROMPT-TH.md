# Master Prompt — Software Engineering Workflow

```text
ใช้ Software Engineering Skills Pack กับ Project นี้

ดำเนินงานตามลำดับ:
1. 01-requirements-engineering
2. 02-system-design
3. 03-software-architecture
4. 04-database-design
5. 05-api-design
6. 06-code-quality
7. 07-testing-qa
8. 08-debugging-refactoring เมื่อมี Bug หรือ Technical Debt
9. 09-owasp-security
10. 10-devops-cicd

กติกา:
- แต่ละขั้นให้ตรวจสอบ Input จากขั้นก่อนหน้า
- ระบุ Assumptions และ Risks
- ห้ามข้ามไปเขียน Code หาก Requirement/Design ยังไม่ชัด
- ทุก Design Decision สำคัญต้องมีเหตุผลและ Trade-off
- ทุก Finding ต้องมี Evidence หรือเหตุผลรองรับ
- Testing ต้อง Mapping กับ Requirement
- Security Review ต้องทำก่อน Release
- CI/CD ต้องมี Quality Gate และ Rollback Plan

เมื่อจบแต่ละขั้น ให้สรุป:
1. Outputs
2. Decisions
3. Risks
4. Open Issues
5. Next Step
```
